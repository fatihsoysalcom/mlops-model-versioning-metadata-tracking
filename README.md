# MLOps Model Versioning Metadata Tracking

This example demonstrates a fundamental MLOps concept: tracking model versions and associated metadata. It simulates a simplified machine learning workflow, including data generation, model training, and evaluation. The core idea is to log parameters, performance metrics, and a unique identifier for each training run, along with saving the trained model, enabling reproducibility and easier deployment management.

## Language

`python`

## How to Run

1. Ensure you have Python 3 and scikit-learn installed (`pip install scikit-learn`).
2. Run the script: `python main.py`
3. Observe the generated model files and metadata logs in the `models/` directory.
